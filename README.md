# DesktopToys 🪴

macOS 바탕화면 위에 놓이는 작은 창문 위젯. 창밖으로 실제 날씨(Open-Meteo)가 보이고, 창틀 위 화분에서 실제 재배 가이드대로 식물을 키워요.

- 다운로드: [Releases](../../releases/latest) 에서 `DesktopToys.zip`
- 설치 방법: zip 안의 `설치방법.txt`
- macOS 13+, Apple Silicon / Intel

빌드: `./build.sh` · 배포: `./release.sh 1.0.1 "노트"`
